# Preparación de alojamiento DEMO
Aplicación estática Vite, origen raíz HTTPS, Node 22, build npm run build, carpeta dist. Instalación de dependencias: npm ci cuando se integre lockfile; actualmente npm install. No variables de entorno, base de datos, API, pagos ni proveedor Microsoft. Publicar solo bundle aprobado y datos sintéticos; mantener una única rama main. No habilitar despliegue automático sin autorización. Alojamiento aún no creado.
Aceptar tras validar CI del SHA, HTTPS, manifest, iconos y service worker, smoke de navegación con datos ficticios, instalación física escritorio/Android/iOS y respaldo recuperado en perfil nuevo. Sin red privada ni datos laborales; la demo no autentica ni sincroniza. La actualización no debe borrar registros del mismo origen; cambiar de origen no traslada almacenamiento, usar copia DEMO. Rollback a build previamente comprobado, revisar compatibilidad de esquema antes de revertir. Coste del proveedor debe confirmarse antes de crear recursos.
