# TalentDesk 1.0
Gestiona talento, impulsa equipos.

Herramienta web/PWA monousuario para organizar procesos de reclutamiento. Dirección visual Studio. Candidato DEMO 0.1.0: Inicio, Vacantes, Configuración, Candidatos, Llamados, Entrevistas e Ingresos validados en DEMO anterior; Documentos, Reportes y tareas validados en DEMO anterior. Automatización solo simulada localmente. PWA (manifest, iconos, service worker sin caché) y respaldo/recuperación como candidato pendiente de CI y prueba física. Autenticación pendiente.

Este repositorio público contiene solo código genérico, documentación pública y ejemplos sintéticos. No debe contener datos personales reales, documentación laboral confidencial ni secretos. El uso real requiere autorización institucional y un entorno aprobado. La DEMO almacena datos ficticios solo en el navegador; no sincroniza ni protege datos mediante autenticación.

Comandos previstos (Node 22):
- npm install (npm ci cuando se incorpore el lockfile)
- npm test
- npm run build
- npm run dev
